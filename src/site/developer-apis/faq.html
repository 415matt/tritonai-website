Frequently Asked Questions

Who can request TritonAI Developer API access?

UC San Diego faculty, staff, researchers, and sponsored student projects may submit a request. Eligibility and the appropriate access path are confirmed from the use case, sponsorship, data, and intended audience.

What data can I use?

Do not assume that a data classification is approved for every model or project. Describe the data in your request so the service team can identify the appropriate route, controls, and any required privacy, security, or service-owner review. Restricted or health information requires a separately approved service path.

What's the difference between UC-hosted and enterprise cloud models?

Both may be available through the common gateway. They differ in capability, hosting, rate, and approved controls. The right choice depends on the task and data—not a universal model ranking. Review the Model Hub for the current catalog and published rates, then confirm the project route during intake.

Does access include a fixed credit allocation?

Allocations, rates, and recharge requirements can change. The access response and Model Hub are the authoritative sources for the allocation and cost rules that apply to your project. Usage should not continue beyond an approved allocation or billing arrangement.

Can I use the API for a production application?

A working prototype does not by itself authorize production use. Production readiness is reviewed from the application's audience, data, integrations, accessibility, security, support model, monitoring, and accountable owners.

How long does review take?

Timing depends on the use case and any required project-specific review. Submit complete information about the task, data, audience, sponsorship, and ownership to help the team identify the next step.

How do I get help or report issues?

For support inquiries or to report issues, email tritonai@ucsd.edu to create a support ticket.
